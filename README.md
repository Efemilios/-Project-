# 🚗 AutoDealer — Σύστημα Διαχείρισης Εξοπλισμού Αυτοκινήτου

**Εργαστηριακό Project** | Τεχνολογία Διαδικτύου στην Ψηφιακή Βιομηχανία  
Πανεπιστήμιο Δυτικής Αττικής — Τμήμα Μηχανικών Βιομηχανικής Σχεδίασης και Παραγωγής

---

## 📋 Σενάριο

Η εφαρμογή προσομοιώνει το πληροφοριακό σύστημα μίας **αντιπροσωπείας αυτοκινήτων**.  
Επιτρέπει στο προσωπικό να:

- Καταχωρεί αυτοκίνητα με βασική τιμή
- Διαχειρίζεται το διαθέσιμο εξοπλισμό (ταξινομημένο σε κατηγορίες)
- Δημιουργεί **quotes** για πελάτες — επιλέγοντας αυτοκίνητο + εξοπλισμό και υπολογίζει αυτόματα την **εκτιμώμενη τελική τιμή**
- Αποθηκεύει και ανακτά ιστορικό προσφορών

Αφορά εφαρμογή Ψηφιακής Βιομηχανίας στον τομέα **διαχείρισης πωλήσεων & πελατών**.

## 🏗️ Αρχιτεκτονική Εφαρμογής

```
car_dealership/
├── db.php                  # Σύνδεση με βάση δεδομένων (mysqli)
├── index.php               # Dashboard — Αρχική σελίδα με στατιστικά
├── cars.php                # Διαχείριση αυτοκινήτων (CRUD)
├── equipment.php           # Διαχείριση εξοπλισμού (CRUD)
├── configurator.php        # Διαμόρφωση & υπολογισμός τιμής (live JS)
├── configurations.php      # Προβολή αποθηκευμένων quotes
└── car_dealership.sql      # Schema + sample data βάσης δεδομένων
```

**Τεχνολογίες:**
- **Backend:** PHP 8 (procedural, mysqli)
- **Frontend:** HTML5, Bootstrap 5.3, Bootstrap Icons, JavaScript (Vanilla)
- **Database:** MySQL / MariaDB
- **Server:** Apache (XAMPP)

## 🗄️ Δομή Βάσης Δεδομένων

### Πίνακες

| Πίνακας | Περιγραφή |
|---|---|
| `cars` | Αυτοκίνητα (μάρκα, μοντέλο, έτος, χρώμα, βασική τιμή) |
| `equipment_categories` | Κατηγορίες εξοπλισμού (Ασφάλεια, Άνεση, κλπ) |
| `equipment` | Επιλογές εξοπλισμού με τιμή ανά μονάδα |
| `car_configurations` | Αποθηκευμένα quotes ανά αυτοκίνητο + πελάτη |
| `configuration_equipment` | Many-to-many σύνδεση quote ↔ εξοπλισμός |

### Σχέσεις (ERD)

```
cars ──< car_configurations >──< configuration_equipment >── equipment
                                                               │
equipment_categories ──────────────────────────────────────── ┘
```

## ⚙️ Οδηγίες Εγκατάστασης (XAMPP)

### Απαιτήσεις
- XAMPP (Apache + MySQL + PHP 7.4+)
- Browser (Chrome / Firefox)

### Βήματα

1. **Αντιγραφή φακέλου**  
   Τοποθετήστε τον φάκελο `car_dealership/` στο:  
   `C:\xampp\htdocs\car_dealership\`

2. **Εκκίνηση XAMPP**  
   Ανοίξτε XAMPP Control Panel → Start **Apache** + **MySQL**

3. **Εισαγωγή βάσης δεδομένων**  
   - Ανοίξτε browser → `http://localhost/phpmyadmin`
   - Κλικ **"Import"** (πάνω μενού)
   - Επιλέξτε το αρχείο `car_dealership.sql`
   - Κλικ **"Go"**

4. **Εκκίνηση εφαρμογής**  
   Ανοίξτε browser → `http://localhost/car_dealership/`

## 🌐 Δικτυακή Αρχιτεκτονική (Μέρος Β)

Η εφαρμογή τρέχει σε `http://localhost/car_dealership/` (Apache port 80).  
Στο Cisco Packet Tracer η τοπολογία υλοποιεί κυκλικό δίκτυο 5 routers / 2 switches / 2 PCs με OSPF dynamic routing, όπου PC1 πραγματοποιεί HTTP GET request προς τον web server (Apache) που φιλοξενεί την εφαρμογή.
